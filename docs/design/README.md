# Agent Session Monitor 디자인 안내

이 문서는 로컬 세션 조회·작업 회고·에이전트 분석을 위한 프로젝트 전용 기준이다.
실제 데이터와 현재 작업을 먼저 보여주고, 필요한 상세를 요청할 때 공개한다.

## 읽는 순서

이 안내 → 변경 영역의 지침 → 해당 화면 계약 순으로 읽는다.

| 변경 영역 | 기준 |
|---|---|
| 브랜드·지정색·참고 이미지 | [브랜드](brand.md) |
| 정보량·여백·반응형 | [레이아웃](layout.md) |
| 탐색·입력·저장·상태·차트 | [컴포넌트](components.md) |
| 글자·대비·키보드·확대 | [접근성](accessibility.md) |
| 7개 화면의 순서와 완료 조건 | [화면 계약](pages.md) |
| 출처·이관 판단·적용 상태 | [이식 기록](adoption.md) |

## 우선순위와 가드레일

현재 사용자의 명시적 요구 → 사용자가 지정한 이미지의 참조 범위 → 이 프로젝트의
확정된 디자인 기준 → 기본 참고 지침 순으로 시각 방향을 결정한다.
기능·권한·데이터 계약 변경은 이 우선순위와 별도로 판단한다.

- 색상·글꼴·테두리·차트 색의 원본은 [Streamlit 설정](../../.streamlit/config.toml),
  간격·배치의 원본은 [공통 CSS](../../src/agent_monitor/ui/styles.css)다. 같은 값을 화면마다 복사하지 않는다.
- 페이지마다 H1 하나를 두고 섹션 제목은 H2, 하위 설명은 H3 순서를 지킨다.
- 제목·필터·본문·하단 행동의 좌우 기준선을 공유한다. 상단 진입 여백과 영역 간격을 구분한다.
- 카드·아이콘·통계로 빈 공간을 채우지 않는다. 오류·필수 입력·현재 선택은 접힌 영역에 숨기지 않는다.
- 원본 로그와 사용자 입력을 HTML·CSS·JavaScript로 실행하지 않는다. 스타일에는 신뢰한 로컬 CSS만 사용한다.
- 수정한 영역의 실제 열림·선택·실패·비활성 상태를 검사한다. 문서나 참고 자료의 테스트 결과를 제품 검증으로 대체하지 않는다.
- 서비스 스냅샷·집계·MCP·SQLite 계약을 보존한다. 미확인 사용량을 0으로 바꾸지 않는다.
- 소스 변경 후 관련 테스트와 `graphify update .`를 실행하고 [검증 기록](../validation.md)에 실제 확인 범위를 남긴다.

이 문서 묶음은 외부 참고 폴더 없이 읽고 구현할 수 있어야 한다. 이후 지정색·이미지 요청도
[브랜드 절차](brand.md)에 따라 분석하고 이 영구 문서를 갱신한다.

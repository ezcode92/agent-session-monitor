# 공통 컴포넌트·상태

[디자인 안내](README.md)

## 탐색과 상태 복원

`navigation.py`가 페이지 이름·파일·URL의 단일 목록이다. `st.Page`·`st.navigation`으로
현재 페이지, 링크 이동, 직접 URL 진입과 브라우저 뒤로·앞으로 이동을 제공한다.
공통 필터는 진입점에서 렌더링한다. 페이지별 검색·선택은 `presentation.remember`를 사용해
위젯 정리와 별개의 세션 상태로 보관한다. 필터 URL 공유와 브라우저 종료 후 초안 복원은 제공하지 않는다.

작업 이력은 같은 에이전트의 세션 ID·부모 ID로 상세를 선택한다. 목록의 행 구성이 달라지면
이전 셀 위치를 초기화한다. 상세의 요청·로그·실시간·회고는 선택한 보기만 렌더링한다.
`st.tabs`에 모든 보기를 동시에 렌더링해 원문 조회나 polling을 늘리지 않는다.

## 입력과 저장

- 모든 입력에 보이는 라벨을 둔다. placeholder는 라벨을 대신하지 않는다.
- 한 작업 영역의 주요 행동은 하나 또는 없음이다. 저장·요청 생성은 primary, 조회·내보내기는 보조 행동이다.
- Select는 값 선택에 사용한다. 키보드 방향키·Enter·Escape, 긴 선택값, 열림·오류·비활성 상태를 검사한다.
- 펼침은 원문·근거·추가 지표에 사용한다. 열린 내용은 늘어나도 트리거의 크기·padding·글자·화살표 간격은 유지한다.
- Native form 제출에서 기존 저장 서비스를 한 번 호출한다. 실패 후 입력을 지우지 않고 오류와 재시도를 제공한다.
- 신규 개선 항목 입력은 성공한 뒤에만 초기화한다. 이미 채택·기록한 근거는 기존 저장소의 중복 방지 계약을 유지한다.
- 실제 저장 성공 후 성공 메시지를 표시한다. 검증 실패·저장 실패를 완료로 표현하지 않는다.
- 기본 설정 복원은 경로·시간대·입력 중 변경을 교체한다는 안내와 확인·취소 행동을 제공한다.

## 데이터·차트·피드백

- 지표에는 명확한 이름·단위·툴팁을 둔다. 알 수 없는 사용량은 `—`, 확인된 0은 `0`이다.
- Plotly는 native Streamlit 테마를 사용한다. 제목·설명·단위·범례와 원자료 또는 집계 데이터 표를 함께 제공한다.
- 시간은 화면에서 시:분:초로 표시한다. CSV 원본의 초 단위와 집계 규칙은 바꾸지 않는다.
- 처음부터 데이터가 없음, 필터 결과 없음, 검색 결과 없음, 갱신 실패를 구분한다.
- 갱신 성공 시에만 화면 스냅샷을 교체한다. 실패 시 이전 데이터와 필터를 유지하고 다시 시도할 수 있게 한다.
- 상태는 글자로 함께 표시한다. 에이전트 분석 요청을 만들었다는 사실과 실제 에이전트 실행·완료를 구분한다.
- 원문은 요청할 때 읽는다. 사용자 문자열을 신뢰한 HTML이나 스타일로 주입하지 않는다.
- 선택 세션의 토큰 합계는 현재 필터에 해당하는 직접 사용량만 합산한다. 요청당 평균은 해당 토큰 항목이 확인된 요청으로 계산하고 확인 건수/전체 요청 수를 표시한다.
- 요청별 도구 이력은 파서가 기록한 요청 ID와 같은 에이전트·세션의 호출 ID를 사용한다. 시간 구간만으로 연결하지 않는다. 미확인 입력·결과·모호한 연결을 성공이나 호출 없음으로 단정하지 않는다.
- 토큰 표는 기간·모델 필터를 따르지만, 선택 요청의 도구 이력은 해당 요청의 전체 근거를 표시한다. 미리보기는 1,000자로 제한하고 전체 원문은 사용자 조작 시 검증된 조회 경로로만 읽는다.

기존 native 아이콘과 글자 라벨을 사용한다. 새로운 장식 아이콘·로고·외부 라이브러리를 추가하지 않는다.
향후 로컬 SVG를 채택한다면 원본·버전·출처·라이선스·해시를 함께 보존하고 이름·포커스·두 테마를 검증한다.
